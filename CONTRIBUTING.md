# Contributing

Thanks for helping improve pzip. Please open an issue describing a bug or proposed change before large work. Include Android version, device type, steps to reproduce and expected behavior for bugs. Avoid uploading personal files or screenshots containing private data.

For code changes, create a focused branch, run `:app:testDebugUnitTest`, `:app:lintDebug` and `:app:assembleDebug`, and describe manual checks in the pull request. Keep UI controls reachable on small screens and honor Android insets. New dependencies should include license and maintenance rationale.

Security issues should follow [SECURITY.md](SECURITY.md), not a public issue.
