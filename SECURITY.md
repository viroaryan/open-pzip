# Security policy

Please do not disclose a suspected security vulnerability in a public issue. Contact the maintainer at **aryankush2354@gmail.com** with affected versions, reproduction steps and impact. Do not include private user files. We will acknowledge reports as we can and coordinate a fix and disclosure.

Only APKs linked from the [official releases repository](https://github.com/viroaryan/pzip-releases/releases) should be treated as official downloads. Confirm the release's checksum before installation when one is provided.
